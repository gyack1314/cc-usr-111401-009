# 资料与既有接口约定

nested.py 使用MISSING表示路径缺席，与None不同。数组原位置从0起；LEFT展开遇MISSING、null或空数组时各产生一个有reason的外占位，元素本身为null则是有位置的真实元素。多数组模式只有cross和zip，zip最长对齐，短侧补pad占位；不能自动选择模式。关系AST的alias是词法作用域标识，路径可引用当前及外层已绑定alias，ON在补外占位前判TRUE，WHERE在后。当前接口只读取路径和枚举单层元素。

所有资料均为合成，字段、身份及状态按本文解释。源码中的 inspect 入口只读取并核对现有基础接口；不会建立高级查询或仓库管理流程。
